# 动效镜头需求单

- 类型：风格叠加 / 账号外观 / 镜头（hook | concept | transition）
- 风格：赛博 HUD / 贴纸拼贴 / 综艺花字 / 其他：
- 服务产品线：explainer / showcase / 英语（可多选）
- 用途一句话：观众在这几秒应该感到或看懂什么
- 画幅：9:16 / 16:9
- 时长：最短 _ / 默认 _ / 最长 _ 秒
- 时长变化：stretch / hold-end / 由作者提议
- 接管范围：inline / full-frame
- 插槽：名称、type、stage/text、最大字数；icon 精确引用或 media 闭包路径
- 是否承载信息：是 / 否（纯注意力，无第 4 层文字）
- 字幕安全区：按画幅
- 关键画面时刻与口播 cue：
- 声音：建议音效打点与用途 / 由作者提议
- 参考：链接、截图或明确对象
- 不要：
- 批量：同风格 _ 件
- 自检：两个 Theme / 全部声明画幅 / 最短默认最长时长 / seek 与回拖
- 未验证项：

先提三个文字方向，不直接写代码。选定后在用户卡的 `assets/<asset-id>/` 制作与校验；引用其他卡时先声明 references，改造时本地化。提交 Draft 后按既有流程确认准确版本。

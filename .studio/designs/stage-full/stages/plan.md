# stage-full · Plan 阶段指南

一句话：在一座小型纸舞台上，用**同一次折叠装置**把「观察 → 分组 → 解释」演成动作，而不是一页页换幻灯片。示例的 2 / 6 / 11 / 15 秒是可读检查点，不是口播对齐；真实制作按正式口播 cue 重排，不把示例秒数当生产对齐。

## 详表（段 / actor / object / audience view / hinge owner / reading window / transition cause / cue / audio）

| 段 | 时间 | actor 主体 | object 对象 | audience view 观众看到 | hinge owner 铰链归属 | reading window 阅读窗口 | transition cause 转场原因 | cue | audio |
|---|---|---|---|---|---|---|---|---|---|
| S0 开场 | 0.00–1.30 | 台口边条、幕布、标题卡 | 舞台外壳 | 台口滑入，标题卡出现，幕布从中线拉开 | 无（幕布/台口是场景层位移） | 0.30–1.00 标题卡 | 开演 | 0.05 台口 / 0.12 标题卡 / 0.80 开幕 / 0.95 标题卡让位 | 无 |
| S1 搭景 | 1.30–2.20 | 折叠装置 | 四块墙板 + 地面桥 + 立牌道具 | 内板先开、外板随后、地面落下、道具立起；六个纸盒交错落到台面 | rig | 1.95 起「① 观察」 | 开演搭台 | 1.30 内板 / 1.35 地面 / 1.45 外板 / 1.70 道具 / 1.55 起物件交错 | 无 |
| S2 观察 | 2.30–6.00 | 焦点光 + 六个纸盒 | 一排六个纸盒 | 光从左侧扫到右侧，逐个纸盒轻抬 | 无（第 3 层强调） | 保持「① 观察」稳定 | 逐件查看 | 2.30 光起 / 3.35+i·0.30 逐件点名 / 5.20 光收 | 无 |
| S3 分组 | 6.15–11.00 | 托盘 + 六个纸盒 + 指示线 | 两簇：暖色 3 / 冷色 3 | 托盘进入，光分成两池，纸盒沿指示线移到同色托盘 | 无 | 6.60–11.20「② 分组」 | 按颜色找共同点 | 6.15/6.25 托盘 / 6.40 光分池 / 6.70+i·0.42 移动 / 9.55 归位强调 | 无 |
| S4 重建 | 11.20–13.90 | 折叠装置 + 关键纸盒(amber) | 旧景与关键纸盒 | 道具塌 → 外板折 → 内板折 → 整台后退 → 新地点在视野里重新搭起；关键纸盒停在台上 | rig 折叠；`#rig` 只做后退位移/缩放 | 13.55–14.30「③ 解释」 | 换地点、保留共同点（动作完成转场） | 11.20 道具 / 11.45 外板 / 11.90 内板 / 12.45 后退 / 12.75–13.35 重搭 / 13.55 解释标签 | 无 |
| S5 收尾 | 14.30–16.00 | 三步标签 + 幕布 | 全台 | 三枚步骤标签进入并轻强调，幕布合拢 | 无 | 14.35–15.30 三步回顾 | 收束 | 14.35 标签 / 14.95 强调 / 15.40 闭幕 | 无 |

可读检查点：**2s** ① 观察 + 六个纸盒；**6s** ① 观察完成；**11s** ② 分组完成（暖色 3 / 冷色 3）；**15s** 三步回顾。

## 铰链归属（rig vs scene wrapper）

- `example/style.css` 只给纸艺皮肤；几何与角度全部来自卡内资产 `assets/stage-rig/stage-rig.js`。
- rig 拥有铰链旋转：`.hf-rig-wall-inner-left/right`（±86°）、`.hf-rig-wall-outer-left/right`（∓172°）、`.hf-rig-floor`（-90°→0°）、`[data-hf-prop-foot]`（88°→0°）。
- scene wrapper 拥有其他变换：`#rig` 只做后退 `y/scale`；纸盒、托盘、光池只做位移与缩放。
- 展开顺序：内板先开 → 外板随后 → 地面落下 → 道具立起，逐级锁定在 0°。

## 必填字段

- **cue（时间依据）**：每段用正式口播/字词 cue（字符串或 token/nth/within/edge）；示例秒数只是可读检查点。
- **content relation（内容关系）**：本段观看任务与上屏信息 ID（①/②/③ 等）的对应。
- **source asset（来源资产）**：折叠装置来自卡内资产 `assets/stage-rig/stage-rig.js`，本卡 `example/scene.js` 只喂 `{inner, outer, floor, prop}`；字体 `media/SourceHanSansCN-Regular.otf`。
- **continuous state（延续状态）**：跨段保留项（如 S4 关键纸盒 amber 停在台上、S2→S3 的六个纸盒）。
- **transition ownership（交接归属）**：铰链旋转归 rig，其他变换归 scene wrapper；A/B 或跨 Scene 交接写明由谁恢复。
- **limits（显式限制）**：未在 Windows 锁定 Studio 连续播放；声音/字幕未验证；示例静音不代表有声验收。

## 轨道镜头表（轨道档必填；开阔档建议）

表前三行缺一不可：

画风：纸艺微缩舞台（本卡皮肤唯一画法；位图只作镂空道具、纸框内容、台口与墙面贴纸，不作常驻页框）
色板：本卡纸艺色板（暗夜蓝黑底、暖纸、墨、卡纸橙红、X 光冷蓝；语义绿只给放行）
角色：无 ／ 只出手和背影 ／ 帧库 <系列立牌状态集>（同一角色至少 2 个姿势状态）

角色行按实际方案选一项。每行一镜，cue 对应正式口播的实际语义起点。下面以「修补一把雨伞」示范填写，角色选无；不沿用题材与秒数作为生产依据。

| cue 口播词 | 画面里的物（名词） | 它在做什么（动词） | 舞台动作 | 屏上字 ≤8 | 层 | 做法 |
|---|---|---|---|---|---|---|
| 这把伞撑不住了 | 断骨雨伞、修伞台 | 修伞台展开，雨伞随道具脚立起 | rig.build | 断在这里 | 2；附着标注 2 | rig + 墙板与地面展开，雨伞镂空道具 + 道具脚立起 |
| 裂口就在接头旁 | 伞骨接头 | 接头在局部镜头中转向裂口 | inset.broll | 接头裂口 | 2；附着标注 2 | 纸框 + 真实接头近照，局部转向裂口 |
| 修好的伞又撑起来 | 修复后的雨伞 | 雨伞随道具脚立起并锁定 | prop.stand | 可以挡雨了 | 2；附着标注 2 | 镂空雨伞道具 + 道具脚从折下到立起 |

| 舞台动作 | 语义 |

### 硬规则

- 物列不能是「卡片 / 标题 / 文字 / 图标 / 背景 / 画面」，须写具体的物。
- 动作列不能是「出现 / 显示 / 淡入 / 展示」，须写物在做什么。
- 第一镜与最后一镜不是字卡。
- 文字主导镜占全片镜数 ≤30%。
- 单镜 2–8 s，超 8 s 拆镜；结合正式口播对齐核对镜头区间。
- 同一舞台动作连续使用不超过 2 次。
- 每个 Scene 至少一次 rig 或道具动作。
- B 段必须有物，不能只是方块贴图。
- 屏上字每镜 ≤8 字，口播交给第 5 层字幕。
- 表前三行画风、色板、角色缺一不可。

单镜时长不替代 2 秒节奏合同；`hold` 不自动构成有效事件，刻意停顿仍在 Plan 写明原因与区间。五层分工与 A/B-roll 正交：B 接管时 A 隐藏或虚化并冻结，返回时已读内容直接就位；B 的独立解释放第 4 层 B 文字组。新增独立文字仍按 A1 提炼（第 4 层文字提炼口播、保留结论与必要数值单位，不整段照搬；定义见 visual-design「第 4 层文字与阅读」），在实际语义 cue 揭示并遵守阅读保护；第 2 层只承载物与附着短标注，第 3 层只做强调与转场，第 5 层字幕始终在最上方。

### 与现行 Plan 的关系

轨道镜头表写在 Plan 的 `## 轨道镜头表` 节，不替代 `## 导演 Brief` 与 `## 分镜表`；director 检查仍读那两节。分镜表的「观众看到什么」一列必须能在轨道镜头表里找到对应镜。上方详表保留为机制示例，真实制作按本节合同逐镜填写。

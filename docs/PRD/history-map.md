# 公共设计卡 history-map

状态：v1 开发实现。随公共包提供，当前卡目录和运行时使用见[历史卡指南](../../.studio/designs/history-map/GUIDE.md)。

## 目标与范围

用无旁白的历史短片呈现一场战役或整场战争。画面以作战地图桌保持地理关系，以立体模切纸片呈现具体事件，以中文牌子提供日期、地点、人物和因果提示。使用者可选本地音乐，封面默认开启，字幕默认关闭。

## 制作合同

| 阶段 | 合同 |
|---|---|
| Script | 选定时间、地理范围与视角，记录镜头纲要和牌文 |
| Research | 每牌登记事实及来源，另列军服、帽型、人物在场及地图方位等史实底线 |
| Plan | 引用两表并安排镜头和阅读时段。人工确认覆盖两张表 |
| Draft | 共用作战地图桌和九种牌子资产。项目数据决定地图、镜头和牌子时序。暂停的主时间线驱动每帧求值 |
| Final | 走既有确认、封面和质检。无音轨有效，自备音乐以本地 stem 接入 |

## 素材、文字与运行时

- 三皇会战示例包含五镜、18 秒、16:9，以及可复用的文案、研究和计划。示例只携带实际使用的 WebP 和相应许可、摘要。复用仓内思源黑体。
- 文字使用 DOM 牌子。根宿主具备 background、stage、overlay 和 text 四层。Canvas 文字由宿主清单登记。1080 高下信息字至少 48 px，日期与关键数字至少 76 px。同屏信息卡最多两张。可读字与主要动作在 x 120–1800、y 110–800。
- 卡声明宿主锁定的 Three.js 0.160.0。示例与新 Variant 从同一宿主位置复制脚本到工程。文件随工程的依赖闭包进入快照。
- 战斗镜头按「战斗大场面」规则编排与核对，不以三四队士兵充当大场面。
- 常规薄纸片以同底图批量提交，接触阴影批量绘制。比较原版与新例的四个繁忙帧，记录渲染提交、三角形、纹理、程序和同步调用时间。复看参考帧确认变化。
